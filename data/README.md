# Data

This project uses the **CSES Module 5 Full Release**, dated 25 July 2023.

The CSES dataset is not included in this repository. It should be obtained
directly from the Comparative Study of Electoral Systems (CSES), subject to
the applicable data-use and redistribution conditions.

For the replication script to run as provided, place the downloaded CSES
dataset file (`cses5.rdata`) in this `data/` directory.

The analysis uses CSES Module 5 to construct the anti-elite attitude measure,
identify populist voting, and obtain the relevant respondent- and
election-level variables.

**Dataset citation:**

Comparative Study of Electoral Systems. (2023). CSES Module 5 full release 
[Dataset and documentation], 25 July 2023 version. 
https://doi.org/10.7804/cses.module5.2023-07-25
