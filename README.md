# More Permissive, More Populist?

## Electoral Permissiveness and the Translation of Anti-Elite Attitudes into Votes

**Melvin Ongaro**  
University of Geneva

**Status:** Preliminary Research Project — August 2026

## About

This repository contains the paper, academic writing sample, and replication
materials for *More Permissive, More Populist? Electoral Permissiveness and
the Translation of Anti-Elite Attitudes into Votes*.

The project examines whether electoral permissiveness conditions the
relationship between anti-elite attitudes and populist voting. It uses two
complementary research designs: a cross-national analysis of CSES Module 5
data and a within-respondent comparison of Swiss voters who cast votes in
both the National Council and Council of States elections in 2019.

This is a **preliminary research project**, and the manuscript and analysis
may be subject to further revision.

## Data

The analysis uses the **Comparative Study of Electoral Systems (CSES) Module
5 Full Release**, dated 25 July 2023.

The dataset is not included in this repository. Please see
`data/README.md` for information on obtaining the required data and placing
it in the appropriate directory.

For replication, the CSES data file should be placed in the `data/`
directory under the filename:

`cses5.rdata`

## Replication

To reproduce the analysis:

1. Obtain the required CSES Module 5 dataset.
2. Place `cses5.rdata` in the `data/` directory.
3. Open the repository as your working directory.
4. Run `code/analysis_permissive_populist.R`.

The script performs the data preparation, estimation, robustness checks, and
generation of the main tables and figures reported in the paper.

## Requirements

The analysis was conducted in **R**. Required packages are specified in
`code/analysis_permissive_populist.R`.
